# NAICS Training Guide
NAICS classifies establishments based on their primary economic activity, not simply their parent brand. The six-digit 492110 code describes Couriers and Express Delivery Services. The six-digit 336411 code describes Aircraft Manufacturing. The six-digit 541511 code describes Custom Computer Programming Services.
Check the establishment's actual business activity and the official NAICS definitions before assigning a final classification. These examples are not a comprehensive lookup table.
