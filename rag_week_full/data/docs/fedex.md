# FedEx — Example business notes
FedEx provides parcel pickup, express shipping, and delivery services. The primary activity in this training example is courier and express delivery. A plausible NAICS category for this specific activity is 492110, Couriers and Express Delivery Services.
FedEx also performs other logistics activities, so the correct code for a specific establishment depends on what that facility primarily does. This educational example is not an authoritative classification.
